# 대전역–중앙로 시범 구간 에셋 연결

## 후속 지도 연결 수정

- 전체 지도 타일 및 `isStyleLoaded()` 완료 대기를 제거하고 스타일 준비 직후 3D 계층을 시작한다. 지도 자료 이벤트가 반복돼도 3D 갱신이 계속 미뤄지지 않도록 예약 방식을 수정했다.
- 대전역·성심당 모델은 줌 15.5부터 표시 대상이다. 주변 수목 에셋 오류가 전체 3D 계층을 중단시키지 않는다.
- 시범 구간은 화면에 보이는 OSM 도로선에 3D 도로 표면을 얹고, 기존 가로수·가로등·버스 GLB를 재사용한다. 지하도로·교량에는 배치하지 않는다. 도로 폭·나무·차량은 재구성이며 실제 설치·운행 자료가 아니다.
- 도로선·건물 중첩을 피하도록 배치하며 보행 경로 선은 3D 계층 뒤에 그려 가려지지 않게 한다. 경로 미리보기는 새 휠체어 GLB를 사용한다.
- 확인되지 않은 횡단보도·점자블록·정류장·엘리베이터·화장실·공사 표지는 실지도에 임의 배치하지 않는다.
- `verify-pilot-streets.mjs`는 기존 도로 자료로 생성되는 3D 표면과 에셋 인스턴스, 한 번만 다운로드, 축소 정리, 시작 조건을 검사한다. 실제 기기의 GPU 렌더링 확인은 별도다.

기존 대전 지도에 대전역과 성심당 본점 외관을 연결했다. 중앙로역은 지도에 등록된 역 중심 지점과 개별 출입구 모형 보기를 연결한다. 상단의 ‘3D 에셋 살펴보기’에서 16종의 실제 GLB를 각각 회전·확대할 수 있다. 첫 방문 안내를 마친 뒤 지도 위 ‘대전역–중앙로 3D 시범 구간’을 누르면 새 모델로 이동한다. `?pilot=1`도 같은 시작 지점을 제공한다.

## 원본과 재현

- 원본: Higgsfield 프로젝트 `492517c6-a7bf-4b2f-bcfc-ca029794e76e`, 리비전 3의 승인된 GLB.
- SHA-256: `51c4ab869f975fce29ef4b55aaa9ba45453437b777eea5201af57fac5015d101`.
- `python3 scripts/split-pilot-assets.py /absolute/path/to/approved.glb`로 모델별 geometry, material, buffer를 추출한다.
- 산출물은 `public/models/pilot/manifest.json` 및 같은 폴더의 16개 GLB다. Y가 위쪽이며 바닥 중심을 원점으로 맞췄다. 사람 모형은 약 1.7–2m 높이로 정규화했다.
- 원본의 에셋 보드 배치는 실제 지리 좌표로 사용하지 않는다. `src/pilot-data.ts`에서 지도 배치를 별도로 관리한다.

## 위치와 표현 범위

| 장소 | POI 원본 | 건물 원본 | 앱 적용 |
| --- | --- | --- | --- |
| 대전역 | OSM node/355173691 | way/254986473 | 건물 외곽선 중심에 외관 모형 배치 |
| 성심당 본점 | OSM node/6443238585 | way/818788759 | 건물 외곽선 중심에 외관 모형 배치 |
| 중앙로역 | OSM node/9271807350 | 개별 출입구 미확인 | 역 중심 핀 → 출입구 모형 개별 보기 |

위치 자료는 기존 `public/data/places.json`과 `research/city/building.geojson` 스냅샷을 사용했다. 수평 배치와 회전은 지도 건물 외곽선에 맞춘 표현 값이며 세부 형태·높이는 재구성했다. 계단 없는 연결, 시설 운영, 휠체어 이용 가능 여부를 외관에서 추론하지 않는다. 출입구, 엘리베이터, 화장실, 정류장, 벤치 등의 미확인 설치 위치에는 모형을 배치하지 않는다. 건물 클릭은 별도 POI ID를 통해 기존 장소 데이터로 연결된다.

## 로딩과 실패 처리

- 전체 에셋 보드를 지도 시작 시 불러오지 않는다. 대전역 약 480KB, 성심당 약 844KB만 개별 요청한다.
- 지도 줌 16.2 이상, 기울기 10도 이상이며 화면 안에 있는 모델부터 요청한다.
- 한 번 불러온 두 모델은 지도 화면에 머무르는 동안 재사용한다. 축소하거나 평면으로 바꾸면 기존 건물 표현으로 돌아간다.
- 개별 모델 요청이 실패해도 원래 건물과 지도는 남는다. 지도 로딩에 시간 제한을 추가하지 않았다.
- 에셋 보기 화면은 선택한 파일 하나만 불러온다. 이전 미니어처 화면도 하단 링크로 접근할 수 있다.

## 검증

- `node scripts/verify-pilot-assets.mjs`: 실제 GLTFLoader로 16개 파일의 geometry, index 범위, 원점, 크기를 검사. 모델 컨트롤러의 필요 시 로딩, 중복 요청 방지, 지도 원점 이동, 클릭→장소 연결, 재사용, 실패 시 기본 건물 유지 확인.
- `node scripts/verify-map-worker.mjs`: 빌드 결과에 MapLibre worker가 포함되고 실제 도시 스타일 메시지를 처리하는지 확인.
- TypeScript 검사와 프로덕션 빌드 확인.
- 위 검사는 Node에서 수행하며 실제 브라우저의 WebGL 출력 및 사용자 기기 성능 측정을 대체하지 않는다.
