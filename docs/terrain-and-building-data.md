# Terrain and building coverage

## Terrain
Mapzen Terrain Tiles (Terrarium encoding, zoom 12) are cached locally over the map extent. SRTM and GMTED2010 terrain data courtesy of the U.S. Geological Survey; global ETOPO1 terrain data from NOAA. Source attribution: https://github.com/tilezen/joerd/blob/master/docs/attribution.md . Accessed 2026-09-18.

The map uses elevation tint (0.46 opacity), stronger hillshade (0.55 exaggeration), and 20m contours with 100m labels, plus physical MapLibre terrain geometry (default 1.5× display exaggeration; 0/1/1.5/2 settings). Contours are derived from the same DEM and served as 581 view-dependent vector tiles (3MB total); the full 8MB contour source stays outside the public bundle. Fixed elevation colors preserve real differences rather than stretching each neighborhood independently. Custom landmarks, architecture modules, façade details, fixed trees, street props, buses and the traveler use the rendered terrain height. Display exaggeration never feeds route elevation calculations. Bridge decks interpolate terrain at their end points; bridge-route overlays and the traveler share that display surface. This is schematic alignment, not surveyed deck heights or clearance. Terrain mode uses draped map roads instead of duplicate flat road slabs. Nearby-detail culling uses horizontal distance so sea-level altitude cannot hide mountain assets. Route elevation uses a smoothed ~90m grid, sampled at intervals of at least 120m. Routes shorter than 90m and known bridge/tunnel spans are unknown. Elevation is not measured pavement slope and cannot establish wheelchair accessibility, local curb height or cross-slope. It does not change routing decisions or override recorded slope restrictions. Uphill and downhill are both shown as estimated information. Chart vertical scale is visibly disclosed as enlarged.

## Buildings
Overture release 2026-08-19.0 supplements the existing OSM snapshot: 102,567 bounding-box candidates, 57,719 accepted additions, 75,751 total footprints. Existing OSM and custom landmark IDs remain intact. Reject out-of-city, underground/tiny, overlapping, road/water-conflicting and low-confidence candidates. Filtering is conservative; coverage and accuracy are not guaranteed complete. Missing heights use an 8m display fallback and are marked unknown.

Supplement sources: 57,715 from Qian Shi et al., A First High-quality Vector Data of Buildings in East Asian Countries Based on a Comprehensive Large-scale Mapping Framework, Zenodo (2023), https://doi.org/10.5281/zenodo.8174931 , CC BY 4.0; four from OpenStreetMap contributors, ODbL 1.0. Overture building theme is distributed under ODbL. https://docs.overturemaps.org/attribution/#buildings . Footprints were filtered and converted to tiled display geometry. Derived footprint data is downloadable at `/data/building-footprints.geojson.gz`; source counts and acknowledgements at `/data/building-data-report.json`. Individual source provenance is retained in research/city/building-supplement-sources.json.

Validation: route direction reversal, flat terrain, bridge exclusion recovery, short-route unknowns, dataset bounds; source geometry validity and ID uniqueness; tile decoding and style validation. Physical-device performance is not verified by these checks.

3D integration validation: TypeScript check, placement tests (exaggeration, bridge valley crossing, route isolation, resource disposal), production build. The available browser has WebGL disabled, so physical-device 3D rendering and frame rate remain unverified. Actual sidewalk slopes, bridge elevations, cross-slopes and live elevator operation require additional measured/operator data; unknown values remain unknown.
